# Sal7ha – Admin Dashboard Frontend

A web-based admin dashboard developed as part of the Sal7ha graduation project.

## About the Project

Sal7ha is a car service platform designed to help car workshop owners manage their business operations. This repository contains the frontend of the admin dashboard.

## My Role

I was responsible for the frontend development of the admin dashboard, focusing on building the user interface and implementing dashboard features.

## Technologies Used

- Next.js
- React
- TypeScript
- CSS Modules
- npm

## Features

- Dashboard overview and business statistics
- Booking and calendar management
- Inventory management
- Payments and reports
- Notifications and inbox
- Business and account settings
- Authentication pages
- Multilingual support (English and Arabic)

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   git clone https://github.com/mennayasser5656/Sal7ha-Frontend-Development

2. Navigate to the project folder:

   cd Sal7ha-Frontend-Development


3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open http://localhost:3000 in your browser.

## Note

This repository contains the frontend code. Any required backend services, environment variables, or external API configurations must be configured separately.
